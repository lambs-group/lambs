# Lambs Group website

Marketing site for Lambs Group (Warrington). Astro 6 static build, React 19 islands, Tailwind 4.

- Preview: https://lambs-group.github.io/lambs/ (repo `lambs-group/lambs`)
- Production: https://lambsgroup.co.uk (not yet launched)

## Commands

```bash
npm install
npm run dev       # local dev server
npm run build     # static output in dist/ (also rebuilds image sizes and sitemap dates)
npm run preview   # serve dist/
```

## Where things live

- `src/pages/` - routes (each wraps a page component and sets its title/description)
- `src/components/pages/` - page content; `sections/`, `home/`, `motif/`, `private/`, `legal/` hold the pieces
- `src/data/credentials.ts` - single source for certifications and qualifications. Lambs do not hold CSCS, NEBOSH, ECS, Streetworks card, WIRS, GIRS or NERS - do not add them back
- `src/data/image-sizes.json` - generated by `scripts/image-sizes.mjs`; do not edit by hand
- `src/components/pages/legal/company.ts` - company details for the legal pages; anything unknown renders as a visible [TO CONFIRM] marker
- `public/llms.txt` - plain-text business summary for AI tools; keep in step with the site
- `src/content/pages/` - unused stubs kept so the content collection validates
- `workers/forms/` - Cloudflare Worker for form handling (see its README)

## Conventions

- British English. The company is "Lambs Group", never "Lambs UK".
- Internal links in raw `<a>` tags must use `withBase()`, or they 404 on the `/lambs` preview.
- Do not use stock or third-party photos. Only photos of Lambs' own work, with descriptive alt text.
- Images are served as webp with a `-640.webp` variant for srcset (`imgAttrs()` in `src/utils/images.ts`). Keep original photos outside `public/`, as everything in it ships.

## Forms

Contact, careers and Private Works quote forms POST to the Cloudflare Worker in `workers/forms/`, which verifies a Turnstile token and emails the submission through Resend.

- Setup and go-live: [`workers/forms/README.md`](workers/forms/README.md)
- The build reads two GitHub repo variables: `PUBLIC_FORM_ENDPOINT` and `PUBLIC_TURNSTILE_SITE_KEY`
- Secrets (`RESEND_API_KEY`, `TURNSTILE_SECRET_KEY`) live on the worker only

## Deploying

Pushes to `main` build and deploy to GitHub Pages via `.github/workflows/deploy.yml`.

For production on `lambsgroup.co.uk`, set `site` to `https://lambsgroup.co.uk` and `base` to `''` in `astro.config.mjs`. Old-site redirects are in the same file and need a host-level 301 file at launch. Also update the sitemap URL in `public/robots.txt` if the domain changes.
